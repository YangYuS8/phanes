# Examples and Fixtures

These files are contract fixtures, not production resource data.

- `config/phanes.config.json` shows the default local workspace layout and literal `127.0.0.1` runtime bind host.
- `builder/build-request.embedded-minimal.json` shows a builder request for the safe embedded minimal mode.
- `cache/embedded-minimal/manifest.json` and `.cache-complete` show the human-readable cache manifest mirror and completion marker expected by the runtime cache contract.

The embedded-minimal fixture must remain tiny and safe to redistribute. Do not add full copyrighted game resources here.
